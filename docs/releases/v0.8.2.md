# v0.8.2

- Fullscreen sessions show a fixed name, short ID and process-tree RSS row.
- Memory and renames refresh every two seconds. Application output is contained
  above the row across clear, scroll, resize and alternate-screen changes.
- `--no-status` selects native forwarding and host-terminal scrollback.
- Nested manager, new and attach commands are blocked. Existing sessions are
  recognized through process ancestry; management commands remain available.

Existing brokers and tasks keep running during upgrade. Reopen the frontend to
use the new display. The status view reserves one terminal row and uses a
bounded VT renderer. Unsupported terminal extensions use `--no-status`.

Release checks use macOS 15. Terminal regressions wait for cleanup and redraw
rather than depending on a short fixed delay.

The status renderer reconnects without a temporary resize. Captured startup
output is displayed once, including when it arrives before the handshake.
