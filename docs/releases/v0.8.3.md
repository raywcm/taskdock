# v0.8.3

Fix Unicode window titles leaking into the application screen during redraws
and scrolling. This affected fullscreen sessions and monitor previews, including
Codex titles containing Chinese text and Claude Code's spinner.

The ANSI parser is pinned to the UTF-8 fix in
[charmbracelet/x#1008](https://github.com/charmbracelet/x/pull/1008), pending an
upstream release. Other runtime files match v0.11.9.

Existing tasks keep running. Exit and reopen TaskDock to load the fix.
