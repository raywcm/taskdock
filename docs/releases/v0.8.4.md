# v0.8.4

- Detach with Ctrl+Q or F12 in fullscreen and monitor views.
- Remove Ctrl+B and Ctrl+] prefix shortcuts. These keys now go directly to the application.
- Update CLI help, five language packs and keyboard documentation.

Bracketed paste stays literal. Use `attach --no-escape` to forward every key.
Exit and reopen TaskDock to load the new shortcuts. Existing tasks keep running.
